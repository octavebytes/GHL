# GHL CTI Connector for Amazon Connect: documentation

Official documentation for the **GHL CTI Connector for Amazon Connect** by [OctaveBytes](https://octavebytes.com): Amazon Connect calling, live transcript, AI assistant and automatic call logging inside GoHighLevel.

📖 **Live docs:** https://octavebytes.github.io/GHL/

## Contents

| Section | What it covers |
|---|---|
| Product | Overview, features, requirements, security and privacy, FAQ |
| Users | Agent guide, supervisor guide, quick reference |
| Administration | Admin console guide, settings reference, licence guide |
| Installation and operations | Installation, upgrade and rollback, runbook, troubleshooting |
| Technical | Architecture, integration, data and retention, API, protocol, release notes |

## Building locally

```
pip install mkdocs-material pymdown-extensions
mkdocs serve
```

Then open http://localhost:8000.
