    Message protocol¶

    Protocol version 1. Messages are JSON text frames on the WebSocket between call bar, relay server and engine (wss://host/relay?role=bar|engine&token=...). The engine page also forwards a STATE patch to the relay with window.postMessage({nhFrom:"engine", state}) and receives commands as window.postMessage({nhTo:"engine", ...cmd}); those local hops carry the same shapes.

    Rules: every message is an object with a string type. Extra fields are allowed and ignored (a newer client must not break an older server). planned messages are part of the platform design and are refused by the validator until they go live.

    Engine to server¶

    Type Status What it is Fields
    STATE live The engine reports a patch of its state (see STATE_FIELDS). The server merges patches and replays the merged state to bars. state (object; required; state patch)
    HELLO planned First message on a socket: protocol version and client kind, so versions can be negotiated. v (number; required)
    client (string; required; up to 50 characters)
    HB live Engine heartbeat for the seat lease: proves the page is running and carries the agent status text and whether a call is in progress. Sent about every 20 s. The server treats a malformed one as no heartbeat. agentState (string or null; optional; up to 100 characters; the status name only (for example Available); not the object that STATE carries)
    call (string; optional; one of idle, on-call; on-call while any call or after-call work is open; this is what keeps the seat through a network drop)
    RELEASE live The agent chose to log out: the seat is freed at once. Closing the window instead keeps the seat for a short reconnect grace. none

    Server to engine¶

    Type Status What it is Fields
    CMD live A command for the engine (see COMMANDS). Sent by a bar, forwarded unchanged by the server to the verified engine. cmd (object; required; one of COMMANDS)
    ALREADY_OPEN live A second softphone window for the same agent was refused; the engine must stop (socket closes with 4409). none
    IDENTITY_MISMATCH live The Connect user in this softphone is not the agent the room belongs to (socket closes with 4403). expected (string; required; up to 200 characters; the agent the window should be signed in as)
    CONFIG planned Effective admin settings, sent on connect and whenever they change. rev (number; required)
    config (object; required)
    SEAT_RELEASED live The session's seat was released (admin action, expiry or stale). The client must stop and say why. reason (string; required; one of admin, stale, licence, replaced)

    Bar to server¶

    Type Status What it is Fields
    CMD live A command for the engine (see COMMANDS). Sent by a bar, forwarded unchanged by the server to the verified engine. cmd (object; required; one of COMMANDS)
    WRAPUP live The agent's disposition and note for a finished call. id (string; required; up to 100 characters)
    disposition (string; optional; up to 80 characters)
    note (string; optional; up to 1000 characters)
    ASK live A question for the Amazon Q assistant during a call. text (string; required; up to 1000 characters)
    ASSIST_FEEDBACK live Thumbs up or down on an assistant suggestion. id (string; required; up to 100 characters)
    value (string; required; one of up, down, (empty))
    SIMULATE_INCOMING live Development aid: pretend a call is ringing. The server ignores it unless it runs with DEV_MODE=on. phone (string; required; up to 32 characters)
    HELLO planned First message on a socket: protocol version and client kind, so versions can be negotiated. v (number; required)
    client (string; required; up to 50 characters)

    Server to bar¶

    Type Status What it is Fields
    STATE live The merged engine state, sent on every change and on connect. state (object; required)
    PRESENCE live Whether a verified softphone is connected for this agent. engine (boolean; required)
    MATCH live Contacts found for the caller's number. Policy says whether the bar opens one, asks, or offers to create. phone (string; required; up to 32 characters)
    contacts (array; required; up to 50 items)
    locationId (string; optional; up to 100 characters)
    policy (string; required; one of single, multi, none)
    created (boolean; optional)
    PANEL live Data for one side-panel topic (caller, transcript, assist, summary). A null payload clears the topic. topic (string; required; up to 50 characters)
    payload (any or null; required)
    LOGGED live Result of writing a finished call to the CRM. id (string; required; up to 100 characters)
    ok (boolean; required)
    contactName (string; optional; up to 200 characters)
    created (boolean; optional)
    detail (string; optional; up to 500 characters)
    SAVED live Everything for a call is written (note, call item, wrap-up, AI summary): the bar may refresh the CRM page. id (string; required; up to 100 characters)
    contactId (string or null; optional; up to 100 characters)
    summary (string; required; up to 50 characters; state of the AI summary job)
    NOTICE live A short message to show the agent. text (string; required; up to 500 characters)
    NO_ENGINE live A command was refused because no softphone is connected. none
    CONFIG planned Effective admin settings, sent on connect and whenever they change. rev (number; required)
    config (object; required)
    SEAT_RELEASED live The session's seat was released (admin action, expiry or stale). The client must stop and say why. reason (string; required; one of admin, stale, licence, replaced)

    Commands (inside CMD.cmd)¶

    Command What it does Fields
    DIAL Place an outbound call. phoneNumber (string; required; up to 32 characters)
    queueARN (string; optional; up to 300 characters)
    ACCEPT Accept the ringing call. none
    REJECT Decline the ringing call. none
    HANGUP End the agent's connection. none
    MUTE Mute or unmute the agent. muted (boolean; required)
    HOLD Put the customer on hold. none
    RESUME Take the customer off hold. none
    DTMF Send keypad digits to the customer. digits (string; required; up to 64 characters)
    SET_STATE Change the agent status (Available, Offline, ...). name (string; required; up to 100 characters)
    COMPLETE Finish after-call work (or dismiss a missed call). none
    REPORT_STATE Ask the engine to send its full state (the engine page sends this to itself when the socket opens). none

    Socket close codes¶

    Code Meaning Client reconnects
    4403 The Connect user in this softphone is not the agent the room belongs to. no
    4409 A second softphone window for the same agent was refused. no
    4410 The seat was released (administrator, replaced by a newer session, or expired). Show the reason from SEAT_RELEASED and stop; starting again is the user's choice. no

    Engine state patch (STATE.state)¶

    Every field is optional in a patch. Unknown fields are allowed.

    Field Type and notes
    engine (string; optional; starting, needs setup, login required, ready, or an error text)
    call (string; optional; one of idle, incoming, ringing, connected, ended, acw, missed)
    contact (object or null; optional; snapshot of the current call: contactId, direction, phone, queueName, attributes, recorded, connectedAt, endedAt, acwAt, held, holdSince, holdMs, monitors)
    agent (object; optional; {name, username, id})
    queues (array; optional; [{name, arn}] from the agent's routing profile)
    agentState (object or null; optional; {name, type})
    agentStates (array; optional; [{name, type}] the agent can choose from)
    agentStateSince (number; optional)
    muted (boolean; optional)
    dialError (string or null; optional)
    stateMsg (string; optional; failure text from a status change, cleared after 6 s)
    ctlMsg (string; optional; failure text from a call control, cleared after 6 s)
    diag (object; optional; {mp, cust, conn, held, agentHeld, muted})
    monitoring (object or null; optional; {contactId, mode} when this agent is a supervisor listening in)
