# Quick reference card

Document version 1.0 · 25 October 2026 · Applies to release v0.2.0

A one-page summary for agents. Full guide: [agent guide](agent-guide.md).

**Start of day**
1. Sign in to GoHighLevel in Chrome.
2. Open the call panel (right edge) → **Open softphone** → sign in to Amazon Connect in the new window, allow the microphone.
3. Keep the softphone window open. Set your status to **Available**.

**Calls**

| To… | Do this |
|---|---|
| Answer / refuse | **Accept** / **Decline** |
| Call a contact | Click the phone icon on the contact page or in the contacts list |
| Call a number | **Call** tab → type the number (+country code for abroad) → **Call** |
| Call again | **Recent calls** → **Redial** |
| Hold | **Hold**, then **Resume** |
| Mute | **Mute**, then **Unmute** |
| Send digits | **Keypad** |
| End | **Hang up** |
| Finish | Choose **Disposition…**, add a note, **Save & Done** |
| Change status | Click the status pill (not during a call) |
| Fold the panel | **»** (open again from the mini bar) |
| Compact or full view | ▭ button in the panel header |

**During the call:** **Transcript** shows the words and sentiment; **Assist** shows Amazon Q suggestions and **Ask Q**. **Summary** fills in after the call.

**After the call:** "Logged to GHL" then "Saved to GHL". The contact page refreshes by itself when safe.

**If you see…**
- "Softphone window is not open." → **Open softphone**
- "Allow pop-ups for this site…" → allow pop-ups for GoHighLevel, try again
- "Reconnecting…" → wait; the call continues
- "Missed call" → choose **Available** to take calls again
- "No softphone seat is free right now…" → try later or ask your administrator
- "…already open in another window or computer…" → use your open softphone window

**End of day:** close the softphone window so the seat is free. Lock your computer when you leave it.
